# AV Snap: Exclusions & Local Rebuild Specification

This document explicitly details all files, directories, and data formats excluded from this Git repository, why they are excluded, and instructions on how to rebuild or supply them locally for development, testing, and production execution.

---

## 1. Summary of Excluded Categories

| Category | Patterns / Extensions | Reason for Exclusion | Rebuild / Local Setup Strategy |
| :--- | :--- | :--- | :--- |
| **Heavy Scan Datasets** | `*.e57`, `*.laz`, `*.las`, `*.ply`, `*.pcd`, `*.pts`, `*.xyz`, `*.rcs`, `*.rcp` | Multi-gigabyte raw lidar/photogrammetry point clouds (e.g., `Stag_Lodge_To_Align.e57` with 18.8M+ points) that exceed Git repository limits and contain proprietary survey data. | Download from project survey storage or use synthetic point clouds generated via `test_align.py` / `test_engine.py`. |
| **Heavy BIM Coordination Models** | `*.ifc`, `*.ifczip`, `*_aligned.ifc` | Heavy architectural/structural BIM datasets (e.g., `24014 - ... Stag Lodge_Architectural coordination file.ifc`) and generated test export files. | Placed in local testing directory or user download folder; verified via `docs/antigravity-history/verify_export.py` or synthetic IFC tests in `test_ifc_extract.py`. |
| **Python Environments & Dependencies** | `venv/`, `.venv/`, `env/`, `ENV/` | Machine-specific compiled C/C++ Python wheels, binaries, and virtual environments. | Rebuilt locally using Python 3.11 64-bit and `pip install -r requirements.txt`. |
| **Build & Distribution Outputs** | `build/`, `dist/`, `*.egg-info/`, `*.manifest` | Compiled PyInstaller desktop executables, frozen runtime binaries, and intermediate object files. | Rebuilt using PyInstaller with `pyinstaller AV_Snap.spec`. |
| **Bytecode & Interpreter Caches** | `__pycache__/`, `*.py[cod]`, `*$py.class` | Compiled Python bytecode generated automatically at runtime. | Automatically regenerated by the Python interpreter on demand. |
| **Runtime Logs & Scratch Files** | `logs/`, `*.log`, `temp_write_*`, `test_write.*` | Ephemeral diagnostic logs, file I/O scratch extractions, and temporary subprocess point clouds. | Re-created automatically by `src/logger_config.py` upon launching the app. |
| **IDE & System Metadata** | `.idea/`, `.vscode/`, `.DS_Store`, `Thumbs.db`, `Desktop.ini` | User-specific IDE configurations and operating system cache files. | Generated dynamically by operating systems and editors. |

## 2. Heavy Runtime Dependencies & Local Rebuild Instructions

AV Snap relies on high-performance C++ wrapped 3D libraries (`Open3D`, `pye57`, `ifcopenshell`, `PyQt5`). These are excluded from source control and must be initialized in your local environment.

### Recommended Environment Setup:
1. **Prerequisites**:
   * Windows 10/11 (or compatible Linux/macOS)
   * **Python 3.11 64-bit** (Required for pre-built wheel compatibility of Open3D and ifcopenshell)
   * Microsoft Visual C++ 2015–2022 Redistributable (x64)

2. **Rebuilding the Virtual Environment**:
   ```powershell
   # 1. Open PowerShell in the project root:
   cd "I:\My Drive\Products\AV Snap"

   # 2. Create Python 3.11 virtual environment:
   python -m venv .venv

   # 3. Activate environment:
   .venv\Scripts\Activate.ps1

   # 4. Upgrade pip:
   python -m pip install --upgrade pip

   # 5. Install all locked dependencies:
   pip install -r requirements.txt
   ```

3. **Core Dependencies in `requirements.txt`**:
   * `open3d>=0.18.0`: High-speed 3D point cloud processing, voxelization, and Generalized ICP (GICP).
   * `pye57>=0.4.0`: ASTM E57 format reading with libE57/Xerces-C native bindings.
   * `ifcopenshell>=0.7.0`: Native Industry Foundation Classes (IFC) parser, geometry engine, and spatial placement API.
   * `PyQt5>=5.15.0`: Desktop GUI application framework and threading.
   * `numpy>=1.24.0`, `scipy>=1.10.0`: Numerical matrix computations and rigid-body transforms ($SE(3)$).
   * `qdarkstyle>=3.1.0`: Professional dark theme styling.

4. **Running the Application**:
   ```powershell
   python launch.py
   ```

5. **Building the Standalone Executable**:
   ```powershell
   pyinstaller AV_Snap.spec
   ```
   *Output executable will be placed in `dist/AV_Snap/`.*

## 3. Test Files & Synthetic Mock Data

Because full-scale scan datasets (`.e57`) and coordination models (`.ifc`) range from 100 MB to several gigabytes, they are excluded from Git:

* **Synthetic Point Cloud Verification**:
  Run `python test_align.py` to create synthetic in-memory point clouds with known rotational offsets and verify coarse + fine ICP registration convergence.
* **IFC Extraction Verification**:
  Run `python test_ifc_extract.py` to test geometry extraction, spatial hierarchy parsing, and bounding box computation.
* **IFC Spatial Transformation Verification**:
  Run `python docs/antigravity-history/verify_export.py` to validate that rigid-body transforms preserve all physical elements, relationship graphs, and metadata without geometry loss.
